# DSC5003 Student Information Management System

This database course project helps an academic adviser review a student's transcript and plan the next semester. The local web app shows which courses a student can take, which requirements remain open, and the reason for each recommendation. All student records are synthetic.

## Run the application

Use Python 3.11 with SQLite. From the repository root, run the following commands for the full demo, including the advisory model and charts.

```sh
python -m pip install -r requirements.txt
python -X utf8 src/run_all.py
python web_app.py
```

The pipeline builds the database, generates plans, runs the SQL queries and validation checks, and produces local charts and CSV exports. The last command opens the application in your browser. Press Ctrl+C in the terminal to stop it.

For a quick look with just the Python standard library, run `python web_app.py` directly. On first launch it builds the SQLite database and generates study plans. The engine can run its advising rules without the optional model. The Figures page uses charts generated by the full pipeline.

## Try a student case

Open **Students**, search for `3036000004`, and open the student's transcript and study plan. The student earned **D+ (1.3)** in COMP2501 and **F (0.0)** in COMP3312. COMP3312 has a retake recommendation. COMP2501 earns credit and can receive a study tip. After a repeat attempt, the latest graded result determines whether the retake reminder is still needed.

## Repository structure

| Path | Purpose |
| --- | --- |
| `web_app.py` | Local web server and browser interface |
| `src/management_system.py` | Command-line interface |
| `src/build_database.py`, `src/generate_data.py` | Database construction and synthetic record generation |
| `fixtures/enrolment-history.tsv` | Synthetic course attempts for the demo cohort, with no names or contact details |
| `sql/` | SQLite schema used by the app, MySQL 8 schema, and the sample query library |
| `src/recommendation_engine.py` | Course selection, retake and study advice, and optional model |
| `src/run_all.py` | Runs planning, queries, validation, exports, and plotting |

The demo has 1,000 synthetic students and 15,927 course attempts. The code generates the student and catalogue tables locally. The enrolment fixture preserves the exact history used in the demonstration. SQLite files and outputs are generated in `data/` and `output/`.

## Run individual checks

```sh
python -X utf8 src/test_engine_smoke.py
python -X utf8 src/run_queries.py
python -X utf8 src/verify_engine_output.py
```

The smoke tests run independently. The last two commands read the database built by the quick start. To try a newly simulated cohort, run `python -X utf8 src/run_all.py --fresh-rebuild`. This replaces the local database, and the example student's results may change. To restore the demo cohort, run `python -X utf8 src/build_database.py` followed by `python -X utf8 src/run_all.py`.
